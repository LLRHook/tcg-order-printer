TCG Order Printer

One click on a TCGplayer order prints the official packing slip and a matching 4×6 address label.

Checking the print helper…

  1. Install the print helper

    The helper is a small app on your Mac that sends labels to your printer without a print dialog. It needs macOS and Python 3.10+ (python.org). In Terminal, run:

    git clone https://github.com/LLRHook/tcg-order-printer-helper.git
cd tcg-order-printer-helper
./install.sh

  2. Answer the setup wizard

    Pick your label printer, enter your return address, and paste this extension ID when asked:

  3. Restart your browser and check the connection

    Then open any order in the TCGplayer Seller Portal and click Print both next to Packing Slip.
